The interaction

Deliberate focus, never surprise rotation.

Nothing interactive waits for an asset upload. Selection is immediate; rich scenes commit only after wheel rest.

AmbientEqual G/M/C scopes stay fixed. There is no contact carousel hiding the topology.
WheelInstant native picker shows the feed’s short code and global index; rest opens a Focus Lens that scrolls NASA’s friendly name when that craft has a config entry, otherwise the complete live short code. Unsupported custom-font characters appear as ?.
STARTA cached line starts immediately and enters Instrument. A cold line says PREPARING and stays put—never autoplaying later.
HoldCycles Network → Instrument → Distance while preserving the selected contact.
TapStarts or releases the existing Distance watch when a usable range is known.

Source-driven one-shot · implemented

Observed Handoff Echo

When adjacent accepted snapshots unambiguously move one craft association and both dishes publish pointing, production pulses the old measured endpoint, shows the complete craft/dish label, then pulses the new endpoint. The mutually exclusive 6/8/6-frame phases are cached as one composed asset, so text cannot cover either measured cell. No cross-scope path is drawn.

Spatial truth

One measured aim, one cell

Azimuth/elevation belong to a dish. Multiple contacts on one dish share one spatial point with a nonspatial tally. Collisions never get decorative jitter.

Built, now optional rollback

Triptych + Focus + Tail

This equal Three Skies triptych is retained under DSN_NETWORK_STYLE=skies, but it no longer defines ambient Network by default. Wheel focus temporarily enlarges the selected site and scrolls one complete available identity. Only the selected dish receives a short observed trail. Instrument and Distance remain the deeper levels.

  • Contact totals are attached to site labels—never unexplained right-edge digits.
  • Exact receive-stream count stays in Instrument.
  • A true-position Handoff Echo pulses the two observed local-sky cells; missing pointing falls back to complete native text.
  • Dish Roster is the default; the older paged contact rows remain a second rollback.
  • Eight-sector roses remain a historical physical-panel fallback study.

Do not build

Decorative liveness

  • No continuously sweeping radar.
  • No invented spacecraft positions.
  • No automatic Focus Lens rotation.
  • No rate-controlled propagation speed.
  • No cross-scope handoff path.
  • No clipped labels or mystery counts.
