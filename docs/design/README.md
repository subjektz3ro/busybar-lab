displays. Open the HTML files directly in a browser to compare the layouts.

They are retained as design context, not as implementation instructions or a
project backlog. Some details may differ from the current app; use
[`apps/dsn.md`](../../apps/dsn.md), the production renderer, and its tests as
the source of truth.
